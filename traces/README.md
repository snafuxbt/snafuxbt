# Traces

A public, growing database of viral statistics traced back to whoever actually measured them. One file per claim, with the chain of sources and a verdict.

Verdicts: `measured` (traced to a real measurement), `distorted` (real source, wrong number or context), `no-measurement-found` (trail ends at nobody).
